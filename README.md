# b2v-annotator
A tool to annotate ground-truth for Board2vec. Backend made by me and frontend made by Gemini

## Folder structure
```
.
├── data: input data
│   ├── keyframes
│   └── obb
└── src
    ├── backend: server to sync progress
    │   ├── app
    │   ├── domain
    │   └── infra
    └── frontend: main application
        ├── core
        └── ui
            ├── components
            └── screens
```
